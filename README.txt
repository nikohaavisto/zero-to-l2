ZERO TO L2 TECHNICIAN - installable app
=======================================

Try it right now (Mac): double-click index.html. It opens in your browser and works offline.

Install it as an app on iPhone and Mac (one-time setup, about 10 minutes):

1. Put this folder online for free with GitHub Pages
   a. Make a free account at github.com and sign in.
   b. Click + (top right) > New repository. Name it zero-to-l2, choose Public, click Create repository.
   c. Click "uploading an existing file". Drag in ALL the files from this folder (not the folder itself). Click Commit changes.
   d. Go to Settings > Pages. Under "Branch" choose main and / (root), click Save.
   e. After a minute or two your app is at: https://YOUR-USERNAME.github.io/zero-to-l2/

2. Install it
   iPhone: open that address in Safari > Share > Add to Home Screen.
   Mac:    open that address in Safari > File > Add to Dock.

After the first open it works offline. Progress is saved on each device; use
"Move progress between devices" at the bottom of the Course page to copy it across.

Updating: upload the new files over the old ones in the same repository.
The installed app picks up the new version the next time it opens with internet.
